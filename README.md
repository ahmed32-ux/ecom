MyStore – MERN Stack E-Commerce Website 🛍️

Welcome to MyStore, a full-stack E-Commerce application built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js).

This project provides a modern and user-friendly online shopping experience with dynamic product and category management, product search, shopping cart functionality, and an admin dashboard.

🚀 Features
Modern and responsive user interface.
Dynamic product listing and category filtering.
Product search functionality.
Shopping cart functionality.
User authentication (Login & Signup).
Admin dashboard for managing products.
Add, update, and delete products.
Add, update, and delete product categories.
MongoDB database integration.
RESTful API using Express.js and Node.js.
🛠️ Technologies Used
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
API Requests: Axios
Routing: React Router DOM
🎯 Project Goal

To build a complete MERN Stack E-Commerce platform that makes online shopping simple, convenient, and efficient while providing administrators with easy store management tools.
